# 2026-10-08 收尾验收

环境：本机 Steam/Proton PPT2，EXE SHA256 与 `profiles.json` 的 build 15220611 配置一致。测试通过游戏菜单进入本地双人 Tetris VS；1P 主要空闲，Bot 控制 2P。这些结果验证接入与操作，不作为对战强度评估。

## 本次修复

- 求解后重新核对棋盘、Next、Hold 和当前方块，状态变化时丢弃旧计划。
- 整条指令链持续检查换块计数与方块类型，覆盖慢速等待、按键按住和相邻动作之间的自然换块。
- 对局对象、玩家对象变化或对局时钟回退时中止旧指令。
- 搜索按出生位置生成路径；手动或中断移动后，非 Hold 路径等待新方块，Hold 路径可恢复居中位置。硬降前核对方块类型、方向、横坐标与实际落地高度。
- 硬降在短按后释放，再等待锁定或 Next 回执，最长等待 2 秒。解决消行动画移除当前方块指针时偶发的 0.8 秒回执超时。
- 游戏窗口连接失败时清理已创建的手柄；正常结束也保证关闭窗口连接。键盘后端接通 `--focus`。
- 原版配置缺少 `player` 时保留默认 2P；整数型数字统一转成整数 CLI 参数；异常配置结构作为可处理错误报告。

原版 EXE、权重、生成核心和已验证的内存地址均未改变。

## 重复验收

```sh
./build.sh
python3 -m unittest discover -s tests -v
python3 tools/check_gui.py
```

启动 Steam 中的 PPT2，停止已有 Bot，进入本地双人 Tetris VS。依次运行下列检查；1P 确认开始/继续，并在游戏暂停时恢复对局。两个实机检查都有 90 秒上限。

```sh
python3 tools/check_live.py --turns 20 --seconds 90
python3 tools/check_live_gui.py
```

实机检查不修改原版文件；面板检查使用临时用户设置，退出时断开自己的控制器。不要与正常面板 Bot 同时运行。

## 仍保留的范围

实机支持当前已匹配的 PPT2 本地 Tetris VS。PPT1、其他 EXE 版本、键盘完整玩法、TD 实机模板行为，以及与 Windows 原版逐步决策一致性未验证。相杀外し、12 Next / PC stack、双线程调度等未移植功能继续在原版设置清单中明确列出。
