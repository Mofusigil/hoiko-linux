# Basic usage and notes
 Set "player" to 1-4 and play.

 It works PPT and PPT2.
 It only works Sprint, Ultra and VS.
 It doesn't work online.
 Please don't use it online.
 Please don't rewrite [bot config].dll and [bot params].dll.
 Please don't modify.
 Please use at your own risk.


# pad接続
 Enable this and connect the controller.


# Opt1(basic)
<>"player" -- Player.

<>"next" -- Visible next.

<>"speed" -- Speed(%).

<>"thread" -- Number of threads to use for searching.


# Opt2(whether to do)
<>"hold" -- Hold.

<>"TD open" -- TD openers.

<>"自動選択" -- Auto character selection.

<>"相殺外し" -- Counter attack. Trying to avoid offsetting. Trying to accept garbage.

<>"PC stack" -- Stacking that is easy to aim for PCs. Valid when "next" is 12.

<>"S4W" -- Side 4 wide.

<>"TD loop" -- Loop TD openers.


# Opt3(basically needless to adjust)
<>"探索量" -- Beam size. This will be adjusted automatically during the match.

<>"寿命" -- Lifespan(minutes).
